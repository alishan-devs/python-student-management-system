# Student Management System

A beginner-friendly Student
Management System built with
Python.

## Features

- Add a new student
- View Students
- Search Student
- Update Student marks
- Delete Student
- Exit the program
- Input validation for student
name
- Input validation for marks
(0-100)
- Handles invalid menu choices

## Technologies Used

- Python 3
- Dictionary
- Conditional Statements
- While Loop
- For Loop
- User Input
- Input Validation
- Break and Continue
- f-Strings

## How the Program Works

When the program starts, it
displays a menu:

1. Add Student
2. View Students
3. Search Student
4. Update Student marks
5. Delete Student
6. Exit

The user can select an option by
entering a number from
**1 to 6**

## Data Storage

Student records are stored using
a Python dictionary.

Example:

```python
students = {
    "Ali": 85,
    "Ahmed": 72
}
```

The student's name is stored as
the key and marks are stored as
the value.

## Input Validation

The program validates:

- Empty student names
- Empty marks
- Marks below 0
- Marks above 100
- Invalid menu choice

## CURD Operations

| Operation | Feature |
|---|---|
| Create | Add Student |
| Read | View / Search Student |
| Update | Update Marks |
| Delete | Delete Student |
